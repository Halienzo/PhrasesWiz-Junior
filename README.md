# ✨ PhrasesWiz Junior · 短语精灵

An interactive web app for learning English verb phrases (Grades 7-9), built with vanilla HTML/CSS/JavaScript.

## Features

- 📚 Browse verb phrases by semester (7A–9B)
- 🔍 Search functionality
- 🏷️ Tag-based filtering
- 🌓 Dark/Light theme support
- 📱 Responsive design (mobile-friendly)
- 🇨🇳 Chinese translations included

## Live Demo

[https://halienzo.github.io/PhrasesWiz-Junior/](https://halienzo.github.io/PhrasesWiz-Junior/)

## Local Development

Open `index.html` (or `PhrasesWiz Junior.html`) directly in your browser — no build step required.

## File Structure

- `index.html` / `PhrasesWiz Junior.html` — Main application (self-contained: HTML + CSS + JS + Data)
- `app.js` — Application logic (reference)
- `data.json` — Verb phrases dataset (reference)
- `build.js`, `template.js`, `cn-mapping.js` — Build tooling (reference)
